# My Task Manager

A simple desktop task manager built with Python and CustomTkinter.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Save tasks automatically using JSON
- Load saved tasks when the app starts
- Dark-themed graphical user interface

## Technologies Used

- Python
- CustomTkinter
- JSON

## How to Run

1. Install Python.
2. Install CustomTkinter:
   `python -m pip install customtkinter`
3. Run the application:
   `python main.py`
